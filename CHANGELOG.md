# Changelog

All notable changes to Mockdeck are documented here.

## 0.1.0 - 2026-09-07

- Add the `mockdeck_publish` agent tool with semantic color markup and terminal-control sanitization.
- Add `/mockup` generation and `/mockups` full-screen gallery commands.
- Add gallery, preview, and notes views with keyboard navigation.
- Add project/global configuration, atomic artifact persistence, recovery, copy, export, delete, and implementation handoff.
- Bundle the `ascii-ui-design` skill.
- Add deterministic validation, storage, registration, and responsive-rendering tests.
